## 🧠 About PharmaLens

**PharmaLens** is an AI-powered healthcare application designed to identify medicines from images and provide relevant healthcare information.

Using **computer vision, image preprocessing, and deep learning**, the system analyzes an uploaded medicine image and predicts the corresponding medicine along with useful information such as its uses, dosage, and possible side effects.

The goal is to make medicine-related information more accessible through an intuitive image-based interface.

## ✨ Key Features

* 🔍 **Medicine Identification**
  Identifies medicines from uploaded images using a deep learning model.

* 📷 **Image-Based Recognition**
  Supports medicine images captured from packaging or pills.

* 🧠 **Deep Learning Classification**
  Uses TensorFlow for automated medicine classification.

* 👁️ **Computer Vision Processing**
  OpenCV is used for image preprocessing and analysis.

* 💊 **Healthcare Insights**
  Provides information such as medicine name, dosage, uses, and possible side effects.

* 🌐 **Web-Based Interface**
  Users can interact with the application directly through a browser.

* ⚡ **Automated Prediction Pipeline**
  The complete process runs from image upload to medicine prediction.

## 🚀 How to Use

1. Open the PharmaLens web application.
2. Click **Choose File**.
3. Select a medicine image from your computer.
4. Click **Upload Photo**.
5. Wait for the image analysis and prediction.
6. View the predicted medicine and available healthcare information.
7. If the result is not satisfactory, try another clear medicine image.
